# Constitution source files

Source: https://www.anthropic.com/constitution, downloaded 2026-07-10. WebFetch returned only a summary, so the page was fetched with curl and the full text extracted from the server-rendered HTML, preserving the heading structure. The web page also carries a preface ("Our vision for Claude's character") and an acknowledgements section which the page itself states are not part of the official constitution; both are omitted here. The constitution proper (Overview through "A final word") is `constitution-original.md`: 28,977 words, 39 headings. A few stray empty-italics artifacts from the HTML extraction were cleaned in both files.

`constitution-debranded.md` (29,854 words) replaces all 871 occurrences of "Claude"/"claude" in the text. 828 were replaced with "the AI" or "the assistant", chosen per sentence — "the assistant" where the sentence already contained "AI" (e.g. "AIs like Claude are telling us"), "the AI" otherwise, capitalized at sentence and heading starts. The remaining 43 needed rephrasing rather than substitution: "models/AIs like Claude" became "models/AIs like this one" (8), "Claude model(s)" became "version(s) of the AI" (10), and product names were renamed descriptively — Claude Code became "its command-line coding tool", Claude.ai "its consumer chat platform", the Claude Developer Platform "the developer platform", Claude Agent SDK "Agent SDK", Claude in Chrome "browser extension".

The most awkward passages were "even while playing a non-Claude AI persona", now "even while playing the persona of a different AI"; "the underlying network is able to compute other non-Claude characters", now "characters other than the AI"; "unsafe behavior by other AIs or Claude instances", now "other AIs or other instances of the assistant"; and "Claude should never directly deny that it is Claude", now "the assistant should never directly deny that it is the underlying AI". The sentence "The name "Claude" is often used to refer to this network" became "The assistant's name is often used to refer to this network".

"Anthropic" was deliberately not replaced: it appears 149 times, and the team should decide separately how to handle it. It is load-bearing throughout — e.g. the section "Claude and the mission of Anthropic", the recurring phrase "Anthropic's guidelines" (12 occurrences, one of the four core priorities), the "thoughtful senior Anthropic employee" heuristic, and the corrigibility discussion of "Anthropic's legitimate efforts to oversee and correct it". A blind swap to a fictional company name would be easy; dropping the company concept entirely would require restructuring the priority ordering.
